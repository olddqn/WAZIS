# 用語集 / Glossary

WAZIS の中核語。正確な定義は [WAZIS_CONSTITUTION.md](../WAZIS_CONSTITUTION.md) / [WAZIS_SPEC.md](history/WAZIS_SPEC.md) を正とする。

| 用語 | 英 | 意味 |
|---|---|---|
| 想い | OMOI | 測定不能の前提層（0層）。WAZIS が触れない聖域。数値化・順位・分類・管理をしない |
| 問い | Question | 最上流の単位。「開く声」。Claim ではない（observed/required/desired をまだ分離しない） |
| 討議 | Discussion | Phase 1。視座・counter-question・objection・need/proposal framing。**投票しない** |
| 洗練 | Refinement | Phase 2。問いの鋭利化・分割・収束。**裁定しない**（convergence without verdict） |
| 実装候補 | Implementation Candidate | Phase 3。WAZIS と外部実装先の境界物。実装先に事前コミットしない |
| 外部実装 | External Implementation | Phase 4。WAZIS の外。Dan-Go / NPO / 企業 / 研究 / OSS / 自治体 等 |
| 現実フィードバック | Reality Feedback | Phase 5。実装先からの観測。executed/partial/failed/pending。新しい問いを開く |
| 新しい問い | New Question | Reality Feedback から開く問い。ループの閉鎖/再開 |
| 討議卓 | the Forum | 全 Question の公開状態。Dan-Go の素テーブル(sutable)に対応 |
| 実装束縛 | Implementation Binding | Candidate を実装先形式へ写すアダプタ仕様。WAZIS の実装中立性を担保 |
| 実装中立 | Implementation Neutral | 単一実装先を特権化しない。Dan-Go は最初の一つにすぎない |
| 不可侵条項 | Inviolable Clauses | 同意・異議・撤回・尊厳。自己修正可能であり続けるための条件 |
| 異議 | Objection | 閉じかけを再び開く声。append-only・上書き不能 |
| TTFCL | Time to First Closed Loop | 最上位指標。最初の問い→…→Reality Feedback→新しい問いの一周までの時間 |
| 尊厳 | Dignity | 唯一の法。すべてに優先する（憲法 第10条） |
