# Openness-Right Review / 開放性の権利レビュー

- Date: 2026-06-22
- Scope: WAZIS は「custody of openness」より更に還元できるか。WAZIS は system か、それとも right か
- 種別: **レビューのみ**。実装・コード・既存ファイル修正を含まない。
- 規律: **削除を加算より優先。** Dan-Go/WAZIS を再設計しない。
- 接地: `SELF_TRANSLATION_REVIEW`（WAZIS＝openness の custodian・拒否の規律）・`NON_GAPABLE_NEED_REVIEW`・WAZIS 憲法（不可侵条項：consent/objection/withdrawal/dignity・想い 非測定）・dignity（唯一の法）。

> **見出し: Yes、更に還元できる。** 「custody」は openness を*保存する actor* を含意するが、**openness は default 状態**である——Need は何かが侵すまで開いている。ゆえに openness が要するのは *preserver* でなく **violation の不在**であり、それは**全員を拘束する規範＝権利（right）**であって custodian を要しない。**WAZIS は best として「開かれた Need の*憲法的保護*（a right）」と理解される**——「それらを*管理する system*」でなく。**この権利はいかなる protocol よりも fundamental**（dignity を Need に適用したもの）で、system/commons はその*instantiation* にすぎない。kill-test を生き残るのは：**想い（測られぬ源）・dignity（法）・Need は holder のもの（→ 開いたままでよい・self-translate してよい・撤回してよい）・現実は aspect に答えうる**。番人：「right」は既存保護を Need の側から見た **lens** であって新機構でない（reify しない）。

---

## 1. 「custody」は actor を含意するか — Yes（そして過剰）

- 「custody」＝ 保持する者（custodian）＝ **actor**。前稿は WAZIS を「openness の custodian」と呼び、actor を含意した。
- だが `SELF_TRANSLATION` で確立した通り、WAZIS の「貢献」は **拒否の規律**（force/measure/govern/verdict を*しない*）——**positive な「保存」行為でなく、侵害の*不在***。
- **openness は default**：Need は**何かが閉じ/強制/測定/破棄するまで**開いている。openness は能動的に*生産*される必要がなく、**侵されない**だけでよい。
- → **「custody」（actor が保存）は「protection」（侵害を禁じる規範）へ還元できる。** actor 不要。

---

## 2. openness は custodian なしに存在しうるか — Yes

- openness は default ゆえ、要るのは **preserver でなく、権利が honored されること**（全員が force/measure/discard を控える）。
- これは **right（全員への制約）**であって **custodian（単一の保持者）**でない。**権利は custodian を要しない。**
- → openness は custodian なしに存在する——権利が侵されない限り。

---

## 3. WAZIS は system / commons / platform / right のどれか — right

| 候補 | 評価 |
|---|---|
| **system** | ❌ 過剰。WAZIS は processing/causation をしない（SELF_TRANSLATION）。「system」は machinery を含意 |
| **platform** | ❌ 過剰。features/infra を含意。WAZIS の本質は restraint であって feature でない |
| **commons** | △ より近い（開いた問いを可視に共有）。だが*管理される resource/place* を含意——保持されるべき「物」を残す |
| **right** | ✅ **最深**。中心 actor を要さず・全員を拘束し・protocol 非依存の規範的保護 |

→ **WAZIS は best として right（Need が開いたままでよい権利）と理解される。** system/commons/platform はその*instantiation/enforcement* にすぎず、right 自体ではない。

---

## 4. Need が決して claimable でないとき、何が真のままか

never-claimable な Need（例：永続する grief）について真のまま残るもの:
- **存在する**（Need は real・想い に在る）。
- **開いたままでよい**（閉じられない・解決されない）。
- **self-translate しうる**（holder は何かを articulate しうる——たとえ完全な gapable aspect に決してならずとも）。
- **侵されない権利を持つ**（force/measure/discard/verdict されない）。

→ **助けられない Need（never-claimable）すら honored される**——*help* によってでなく（不可能）、*openness の保護*によって（破棄せず・強制せず・測らず・witness する）。**これは非遺棄（non-abandonment）の最深形**：永続する grief は助けられないが、その**開いたままでいる権利は保護できる**（dignity 尊重が救済不能の只中でも成り立つ）。

---

## 5. Need は「開いたままでいる権利」を持つか — Yes

- **Yes。** Need は **開いたままでいる権利**を持つ：discard されない・Claim へ強制されない・measure/rank されない・「解決済み」と verdict されない権利。
- これは WAZIS 憲法の不可侵条項（consent/objection/withdrawal/dignity）＋ 想い 非測定 を、**Need の側から見た統一名**。新権利でなく、**既存保護を Need の視点で命名**したもの。
- 根：**dignity**。Need を強制/測定/破棄するのは、その holder の dignity を侵す。**「開いたままでいる権利」＝ dignity を Need に適用したもの ＝ holder の自己の Need への sovereignty。**

---

## 6. その権利はいかなる protocol よりも fundamental か — Yes

- protocol（WAZIS・Dan-Go）は権利を **instantiate/honor する道具**。Dan-Go は claimable な gap を閉じ、WAZIS は開いた Need を保護する。
- だが**権利（Need は開いたままでよい・侵されない）は protocol に*先立ち・独立して*存在する**——規範的事実であって system feature でない。
- dignity が唯一の法で「他はすべて protocol」（憲法）。**「開いたままの権利」は dignity の発現ゆえ、protocol より上位。** protocol は権利を honor できるが、権利は protocol に依存しない。
- → **権利 > protocol。** WAZIS-the-protocol は権利の一 instantiation（置換可）。権利は不変。

---

## 7. WAZIS ＝「開かれた Need の憲法的保護」か、「それらを管理する system」か — 前者

- **「管理する system」は誤り。** 管理は actor が*する*こと（measure/process/decide）を含意——WAZIS はそれをしない/すべきでない（SELF_TRANSLATION の四原則）。
- **「開かれた Need の憲法的保護（constitutional protection）」が正しい。** WAZIS の本質は、Need が開いたまま・un-forced・un-measured・un-discarded・un-verdicted でいられるという**規範的保証**。
- WAZIS の「system 的」部分（commons・Dan-Go への route・可視性）は、その保護を**実効化する instantiation** であって、本質（権利）ではない。
- → **WAZIS ＝ 保護（right）であって、管理する machine でない。** WAZIS 憲法は、実は**「開かれた Need の憲法的保護」そのもの**を既に符号化している（不可侵条項＋想い 非測定）——本書はそれを*認識*するだけ（削除：system/custodian の framing を外す）。

---

## 8. kill-test を生き残るもの（irreducible 集合）

| 区分 | irreducible | 外すと |
|---|---|---|
| **源（ground）** | 想い（測られぬ源） | 非測定の根が消える；Need の源が消える |
| **法（ceiling）** | dignity | 「侵されない」の根が消える |
| **事実** | Need は存在する | 始点が消える |
| **sovereignty（WAZIS の本質＝right）** | **Need は holder のもの** → 開いたままでよい・self-translate してよい・撤回してよい | 強制/抽出/破棄が可能になる＝侵害 |
| **bridge（Dan-Go/現実）** | 現実は aspect に答えうる（gapable なとき） | closure/reality-arbiter が消える＝kernel が消える |

- ユーザーの 4 つ（exists / may remain open / may self-translate / reality may answer）は概ね正しい。
- 更なる reduction：**「may remain open」と「may self-translate」は一つの根の二面**——**Need は holder のもの（sovereignty）**。他者は force/measure/discard できず（openness）、holder のみが translate でき（self-translation）、holder のみが withdraw できる。三つは sovereignty の発現。
- **WAZIS の irreducible な本質 ＝ この sovereignty の憲法的保護（＝ 開かれた Need の権利）。** それ以上削れない（削れば dignity 侵害）。

---

## 9. 削除優先の番人

- **「right」を新機構へ reify しない。** それは既存保護（不可侵条項＋想い 非測定＋no-governor＋no-verdict）を Need の側から見た **lens** であって、新 registry/enforcement-engine でない。Reification Test：「right」を消しても不可侵条項は Need を守る——何も壊れない＝lens。
- **権利は存在に custodian を要さないが、実効化（honoring）には instantiation を要しうる。** 現実の violator（force/measure/discard する者）に対し、commons・憲法・route という instantiation が権利を*honor*する。だが instantiation は**権利に*仕える***のであって権利を*管理する*のでない（管理＝§7 で否定）。instantiation は置換可、権利は不変。
- **過小評価もしない：** 「WAZIS は単なる抽象的 right」ではない。権利は実効化の器を要し、その器は権利を honor する形（measure/govern しない）に造られねばならない。**削減は WAZIS が*何である*かを明かす（right）——器が不要とは言わない。**

## 10. 統合（一文で）

**WAZIS は「custody of openness」より更に還元できる——「custody」は openness を保存する actor を含意するが、openness は default 状態（Need は侵されるまで開いている）ゆえ要るのは preserver でなく侵害の不在＝全員を拘束する規範＝権利であって custodian を要さず、ゆえに WAZIS は best として system でも commons でも platform でもなく「開かれた Need の憲法的保護（a right）」と理解され、その権利＝Need が開いたまま・un-forced・un-measured・un-discarded・un-verdicted でいられること＝holder の自己の Need への sovereignty＝dignity を Need に適用したものは、いかなる protocol よりも fundamental（protocol は権利を instantiate/honor するが権利は protocol に独立）であり、never-claimable な Need すら help でなく openness の保護によって honored される（非遺棄の最深形）；kill-test を生き残るのは 想い（測られぬ源）・dignity（法）・Need は存在する・Need は holder のもの（→開いたまま/self-translate/撤回してよい）・現実は aspect に答えうる、であって、WAZIS の irreducible な本質はこの sovereignty の憲法的保護であり、「right」は既存の不可侵条項＋想い 非測定を Need の側から見た lens（新機構でない）で、権利は存在に custodian を要さないが実効化には権利を honor する（管理しない）instantiation を要しうる——足すべき機構は無く、WAZIS は管理する machine でなく、開かれた Need を侵害から守る憲法的権利である。**
