# Reality Feedback Interpretation Review / RF 解釈レビュー

- Date: 2026-06-22
- Scope: Reality Feedback（RF）が**新しい権威**になることを何が防ぐか。RF は自らを解釈しない——人間が解釈する。その解釈層の最小形を確定する
- 種別: **レビューのみ**。実装・コード・既存ファイル修正を含まない。
- 規律: **ガバナンスを発明しない・新しい層を発明しない・スコアリングを発明しない・削除を加算より優先。** 既存レビューに在るなら「既出」と明記。
- 前提: 既往7レビューは、直接観察で矛盾しない限り正しい。

> **見出しの答え:** 危険は実在する。だが**それを防ぐ境界はすべて kernel に既出**で、新たに足すべき機構は無い。RF は **「現実が何をしたか」についての権威でしかなく、「何が善・誰が値するか」についての権威では決してない**——後者は 想い の aim（誰かが、本人の定義する形で助かる）に属し、測られないまま据え置かれる。RF が新権威化するのを防ぐのは、**機構でなく『拒否の規律』**: 集計しない・最適化目標にしない・解釈を中央集権化しない・意見を RF と認めない・想いを RF で推し量らない・尊厳を侵して得た観測を RF と認めない。**vote worship を data worship に置き換えない唯一の鍵は、想い非測定（不変項 II）——aim を数にしないこと——で、これは vote と data の両方を同時に塞ぐ。**

---

## 1. RF が新しい権威になるのを何が防ぐか

「権威」を二義に分ける。RF が **裁定者（arbiter）** であることは意図された load-bearing（討議でなく現実が決める）。危険なのは RF が **統治者（governor）**——善悪を布告し、人がそれへ最適化し、その解釈を握る者が支配する——になること。後者を防ぐのは、**既に kernel にある5つの構造的事実**:

1. **RF は中心でない。中心（hub）は 想い の aim。**（META_LOOP §Q4）RF は aim に*仕える*観測であって、aim そのものではない。RF を「最大化すべき善」と扱った瞬間、それが META_LOOP の名指す drift。
2. **RF は閉じず、再び開く（非終端・不変項 III）。** 統治者は*決着*させるが、RF は*未決化*する（あらゆる答えが次の問いを開く）。常に自らを問い直させる以上、**RF は権威として ossify できない**。
3. **RF は複数かつ局所で、集計でない。** 「この実験・この実装先・この観測」。単一の global score としての「the RF」は存在しない。統治には単一/集計が要るが、RF は不可分に plural・文脈依存。
4. **RF は contest可能（Objection は残る）。** 反論不能なら oracle 専制。RF は観測であり、観測は誤りうる・部分的でありうる・争いうる（§4）。
5. **RF は 想い から壁で隔てられている（不変項 II）。** RF は*現実*（何が起きたか）を観測し、*想い*（内面・値打ち）を観測しない。ゆえに RF は「人の値打ち」への権威になれない（§5）。

→ **防御は既出。欠けた safeguard は無い。** 危険は構造の穴でなく、**人間がこれらを忘れて RF を「単一・最終・集計・反論不能な*価値*スコア」として扱う drift**——それが metrics/data-worship への滑落（§2/§6）。

---

## 2. Reality Feedback と Metrics の違い

これが核。鋭く分ける:

| 軸 | Reality Feedback | Metrics |
|---|---|---|
| 集計 | **局所・個別**（一実験の現実との遭遇） | **集計**（多状況を一数へ圧縮） |
| 役割 | **観測**（次の問いを*学ぶ*もと） | **目標**（最大化する*的*） |
| 可換性 | **非可換**（「誰かが助かった」は通貨単位でない） | **可換**（和・平均・順位） |
| 価値との関係 | 価値を*主張しない*。aim（想い）に*仕える* | 価値の*代理（proxy）* |
| 閉じるか | **再び開く**（非終端） | 順位/裁定（閉じる） |

**一文:** **RF は、次の問いを開く*文脈的観測*。Metric は、最大化される*集計された代理*。RF は、集計され・比較され・最適化目標にされた瞬間に Metric になる。** Goodhart の法則（「測度が目標になれば良い測度でなくなる」）は、まさにこの境界の名。

---

## 3. RF はいつ score optimization になるか

次のいずれかが起きた瞬間:
1. **集計:** RF を和/平均/順位で単一スコア化（「executed 率 87%」「この貢献者の成功率 90%」）。leaderboard が計算できたら、もう metric。
2. **目標化（Goodhart）:** スコアを上げるために**問い/実験を選ぶ**（`executed` になりやすい易しい実験を選び、難しい `failed` を避ける）。aim（誰かが助かる）が*的*に置換される。
3. **人/問いの横断比較:** 非可換な「助け」を可換な点へ変換し序列化。
4. **`executed` を `who_was_helped` より優先:** 測りやすい proxy（実行されたか）を、観測しにくい aim（助かったか）より上に置く——古典的 metric 病理。

→ 防御（削除優先）: **集計しない・順位を出さない・RF を最大化可能な数として表示しない・RF を必ずその問いに結び付けて局所に保つ・`executed` を「本人の定義する助け」より優先しない。** PLATFORM の「人を数えるカウンタを持たない」を、**「RF を集計するカウンタも持たない」へ延長**するだけ（新規ゼロ）。

---

## 4. RF 自体は contest できるか

**Yes——できなければ oracle 専制。ただし*投票でなく*。** 既存の Objection ＋ fan-out で足りる（新機構ゼロ）:
- **観測を反証:** 「RF は executed と言うが、私は*助けにならなかった/害になった*と観測する」——対立観測（それ自体が一種の RF/Objection）。
- **再実験:** 最強の反証は議論でなく**もう一度（または変種で）試すこと**。**現実は、より多くの現実によって争われる**——討議によってではない。これが最深点。
- **過程への dignity-objection:** 「その RF は尊厳を侵す過程で得られた」——*どう*得たかへの異議（§7-5 と連結）。

**禁止:** 「我々は現実に不同意ゆえ override する」という**多数決での反証**。それは討議を権威へ復権させる（kernel inversion）。**RF は、より良い/より多い観測・再実験・過程の瑕疵の暴露でのみ争われ、群衆の不同意では争われない。** RF の contest 自体が reality-driven であって discussion-driven でない。

---

## 5. RF と 想い の関係

OMOI 層・META_LOOP の通り: **想い は hub（aim・誰かが助かる）で、測られず・入らない。RF は rim の hinge（観測）。** 関係:
- RF は 想い の aim に**仕える**が、想い を**測らない**。RF は*現実*（世界で何が起きたか）を観測し、*想い*（内面・源・aim）を観測しない。
- RF の問いは「現実に触れたか／誰が助かったか」——*aim について*だが、観測されるのは*現実において*（実際に誰かが助かったか）であって、*想いにおいて*（どれだけ強く望んだか）ではない。
- **禁止（Saiyan Scouter）:** RF を使って 想い を**逆算**すること——「この実験は失敗した、ゆえに背後の想いは弱かった/誤りだった」「成功した実験ほど強い想い」。表面（RF）から内面（想い）を推し量るのは原則違反。RF は膜の*現実側*に留まる。
- **aim の定義者は当事者:** 「助かった」かを決めるのは**本人**（consent/dignity、TTFR「本人の定義する形で助かる」）。RF も データも、「助け」の意味を**定義しない**——本人が定義する。

→ **RF と 想い は膜で隔てられる。RF は現実を観測し aim に仕えるが、想い を測定・序列・推定しない。** だから RF は人を裁けない（想い から壁で隔てられている）——これが「RF が人の値打ちへの権威になれない」根拠。

---

## 6. vote worship を data worship に置き換えないために

「vote worship」＝集計された*意志*（票）を権威とする。「data worship」＝集計された*観測*（metric/RF-as-score）を権威とする。**両者は同一の病理**: 集計不能な aim（誰かが助かる）を一つの数で代理し、その proxy を崇める。WAZIS は権威を現実へ移して vote-worship を脱したが、それを data 形で再輸入する危険がある。

**唯一にして同一の防御（既出・削除優先）: aim を数にしない（不変項 II・想い非測定）。**
- vote-worship も data-worship も、**崇めるための数を必要とする**。WAZIS の aim は数であることを拒む（想い非測定）。崇める対象（aim）が数でない以上、**同じ不変項 II が票崇拝とデータ崇拝を同時に塞ぐ**。
- 補強の拒否規律: RF を集計しない（§3）／aim の定義を本人に残しデータに渡さない（§5・TTFR）／RF を再実験で contest 可能に保つ（§4）／非終端で最終裁定を作らない（§1-2）／測りやすい `executed` を「本人の定義する助け」より優先しない。

→ **RF は「現実が何をしたか」への権威であってよい（観測）。だが「何が善・誰が値するか」への権威には決してならない（それは本人/想い に、測られず残る）。** data-worship は metric が*目標を定義する*時に起きる; WAZIS では目標（助かること）が**本人の 想い に定義され、RF はその現実での実現を観測するだけ**ゆえ、データは目標を定義する地位を得られない。PLATFORM の「単一の削除」と同型——**aim の非数値化、という一つの拒否が両崇拝を塞ぐ。**

---

## 7. kernel を保つ最小の解釈層

RF は自らを解釈しない。だが解釈層は**中央集権の解釈機関でも、スコアリング rubric でも、ガバナンス body でもない**。最小形は、**既存の不可侵条項＋非終端＋Art 2 がそのまま構成する三分**（新層ゼロ・本書は記述するだけ）:

1. **事実の層（「起きたか」）＝ 独立観測。** executed/partial/failed は独立観測（Dan-Go Phase 4）。**権威でなく観測**——誰でも再観測でき、より多い観測で contest 可能（§4）。中央の解釈者なし。
2. **価値の層（「aim に仕えたか／誰が助かったか」）＝ 当事者に主権。** 「助かった」を決めるのは**本人**（consent/dignity/TTFR）。他者が裁定しない。これはガバナンス行為でなく**不可侵条項の適用**。
3. **生成の層（「これは何を開くか」）＝ 誰でも、New Question へ。** RF を読んで疑問/異論があれば、RF への*裁定*を得るのでなく、**新しい Question か対立実験を開く**（Art 2・非終端）。他者の解釈は*権威*でなく*再開*へ流れる。

→ **最小の解釈層は、ガバナンスの意味では「層を作らないこと」そのもの**: 事実は（plural な）観測、価値は当事者の主権、生成は誰でも New Question。**中央集権の「RF 解釈権威」やスコア rubric を置けば kernel が壊れる。** 既に在るもの（観測＋consent＋再開）が最小の解釈層であり、足すのは誤り。

---

## 8. 何を決して RF にしてはならないか

RF（＝「現実の答え」）として認めてはならないもの:
1. **意見・票・討議の結論。** 「討議の結果 X と結論した」は RF でない——討議が現実の仮面を被ったもの。**これを RF と認めれば kernel inversion**（討議が権威へ復権、PLATFORM #1）。最も危険。
2. **予測・見込み。** 「これは1000人を助ける（だろう）」は RF でない（まだ起きていない）。RF は*観測*であって予報でない（「未観測を観測済みとして提示しない」）。
3. **集計スコア/metric。** 計算された成功率は RF でなく、RF から導いた metric（そもそも作るな、§3）。RF は個別観測であって集計でない。
4. **想い の推定。** 「想いが強かった/弱かった」は RF でない——測られぬものへの逆算（Saiyan Scouter）。RF は現実を観測し、内面を観測しない。
5. **尊厳/同意を侵して得た観測。** 強制や無同意で*抽出*した「観測」は valid RF と認めない——不可侵条項は RF の*産出*過程をも gate する。さもなくば RF が加害を誘発する。
6. **WAZIS の自己採点。** WAZIS が自分の成功を観測したものは RF でない——RF は WAZIS が支配しない*外部*の現実から来ねばならない（kernel: WAZIS は実装/自己採点しない）。

→ **統一規則: RF は、外部で観測された・個別の・尊厳清潔な「現実が何をしたか」の事実でなければならない。** 意見・予報・集計・内面推定・汚染された抽出・自己採点は **RF ではなく**、それを RF と認めることは kernel の崩壊である。

---

## 9. 統合（一文で）

**Reality Feedback は「現実がこの個別事例で何をしたか」への権威であってよいが、「何が善か・誰が値するか」への権威には決してならない——後者は当事者の 想い（aim：本人の定義する形で助かる）に、測られぬまま残る。RF が新権威化（data-worship）するのを防ぐのは新機構でなく、kernel に既出の*拒否の規律*である: RF を集計しない・最適化目標にしない・解釈を中央集権化しない・票や予報や内面推定や自己採点や尊厳侵害の抽出を RF と認めない。RF は metric と違って局所・非可換・観測（目標でなく）であり、集計され目標化された瞬間に metric へ堕ちる; RF 自体は——投票でなく、より多い観測・再実験・過程の瑕疵によって——contest 可能であり、非終端ゆえ最終裁定を持たない。vote-worship を data-worship に置き換えない唯一の鍵は、想い非測定という一つの不変項——aim を数にしないこと——であり、それが両崇拝を同時に塞ぐ。最小の解釈層は、ガバナンスを作らないこと：事実は独立観測、価値は当事者の主権、生成は誰でも New Question——すべて既存の不可侵条項と非終端で、足すべき層は無い。**
